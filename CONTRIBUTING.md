# Contributing to PCAP Lab Generator

First off, thank you for considering contributing to PCAP Lab Generator! It's people like you that make this tool better for the cybersecurity community.

## 🚀 How Can I Contribute?

### Reporting Bugs
- Use the [GitHub issue tracker](https://github.com/agugliotta/pcap-lab/issues).
- Describe the bug and provide steps to reproduce it.
- Mention your OS and Python version.

### Suggesting Enhancements
- Open an issue with the "enhancement" label.
- Explain why the feature would be useful and how it should work.

### Pull Requests
1. **Fork the repo** and create your branch from `main`.
2. **Naming Convention**: Use `feature/` for new features or `fix/` for bug fixes (e.g., `feature/add-payloads`).
3. **Tests**: Ensure all tests pass by running `python main.py test`. New features must include new tests.
4. **Code Quality**: Follow PEP 8 guidelines for Python code.
5. **Documentation**: Update the `README.md` or Wiki if your changes affect usage.
6. **PR Description**: Include `Closes #XX` to link the relevant issue.

## 🛠️ Development Setup
- Install dependencies: `pip install -r requirements.txt`
- Run tests: `python main.py test`

## 🛡️ Security
If you find a security vulnerability, please do not open a public issue. Instead, contact the maintainer directly.
